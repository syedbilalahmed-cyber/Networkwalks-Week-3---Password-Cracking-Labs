The purpose of this week's practical work was to understand **password cracking and password auditing techniques** through controlled and authorized cybersecurity laboratory exercises.

# 🔴 PROJECT 01 — John the Ripper & Johnny

## 🎯 Project Objective

The objective of Project 01 was to understand how **John the Ripper** and its graphical interface **Johnny** can be used for password auditing against an authorized password-protected PDF.

The practical exercise included:

- Configuring Johnny
- Detecting John the Ripper
- Loading the protected PDF
- Identifying the PDF hash
- Performing password auditing
- Recovering the password
- Verifying the recovered password
